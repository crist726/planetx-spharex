# Proyecto de Planet X and SPHEREx (Equipo Universales)

Este proyecto se dedica a realizar una aplicación web que muestra
imágenes de la misión de SHAPEx los cuales se introducirán coordenadas
para este, este introducirá cambios en los objetos celestes.

[Link para el proyecto de Hacketon](https://www.spaceappschallenge.org/2026/challenges/planet-x-and-spherex/?tab=details)

## Uso de IA

Usamos IA (Claude) como apoyo.

- Planeación: el plan del proyecto, el reparto de roles, las etapas y
  los contratos entre módulos se redactaron con Claude; el equipo lo
  revisó y lo adaptó.
- Código de referencia: Claude generó ejemplos de cada módulo. Cada
  persona escribió su propia versión y usó el ejemplo para comparar, corregir y realizar mejoras.
- Revisión: usamos IA para <explicar errores / sugerir pruebas /
  mejorar redacción>, y decidimos nosotros qué aceptar.
- README y guion del video: <herramienta>, revisados por el equipo.

Todo el código fue revisado, probado y entendido por el equipo antes
de incluirlo.
